A small guide to nthtml

Read the Nimble Terminal website or browse the nthtml source and examples. Use Tab and Enter to follow links.

What you can build

  • Readable terminal documentation with links and code.
  • Portable document previews:
    • Typeset pixels in a terminal or browser.
    • TTY text with wrapped tables and clickable links.
  • A bounded renderer for your own Go application.

Try it

  1. Build the command-line tool with task build.
  2. Open the documentation demo with task demo DEMO=guide.
  3. Press t to switch layouts, then resize the browser container.
package main

func main() {
    // Indentation and blank lines are preserved.
    message := "Hello, Nimble Terminal"
    println(message)
}

Inline code <like this> uses a monospace face. Long code lines soft-wrap to fit the available width without discarding spaces.
