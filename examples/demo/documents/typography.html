Useful emphasis

Use bold for landmarks, italics for emphasis, and both sparingly. We can underline a phrase or mark outdated information.

Space that adapts

The article uses a percentage width, a maximum width, automatic horizontal margins, and different padding on each side. Switch to TTY layout to read the same content in terminal cells.

article {
    width: 100%;
    max-width: 680px;
    margin: 0 auto;
    box-sizing: border-box;
}

A shared ruler
