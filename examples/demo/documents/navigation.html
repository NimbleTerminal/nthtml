A document worth exploring

Jump to Reading, Finding a phrase, or Copying text.

This guide demonstrates local fragment links, search, and selection. All three work with the rendered document. There is no browser engine behind the terminal view.

Reading

Follow a contents link to jump directly to a section. In the terminal, Tab selects a link and Enter follows it. Clicking a local link scrolls this document instead of opening a browser.

Switch between Typeset and TTY with t. Typeset preserves the document's typography; TTY lays out readable text using terminal cells. Each view has its own text positions, so changing layout or resizing clears an existing selection.

Long documents are easier to explore when navigation remains local. This paragraph adds a little distance between sections so the contents links have somewhere useful to take you.

Finding a phrase

Search for portable documents. Matching ignores case and repeated whitespace, including line wraps. The next sentence repeats Portable Documents so you can try moving between results.

In the terminal, press /, enter a query, and press Enter. Use n and N for the next and previous match. Esc clears the search and selection. Searching for café also demonstrates Unicode text.

In the browser, use the Find field and Previous/Next buttons. Search operates on the same Go text indexes as the native viewer. Resize the container to test a new layout.

Copying text

Drag across text to select it. In the terminal, y asks the host to copy the selection using terminal clipboard support. Press v to select the current search match, or Ctrl+A to select the entire document text.
